# Vantage letter-size posters

Print-ready PDFs for 8.5 × 11-inch paper. Each poster includes a QR code linking
to the [Vantage signup page](https://vantage-player-survey.anofdv3fe.chatgpt.site).

| PDF | Design |
| --- | --- |
| [All three posters](vantage-posters-letter.pdf) | Three-page file for printing the complete color set |
| [Your game. A new Vantage.](01-your-game-letter.pdf) | Orange court and paddle artwork |
| [Play it. Replay it. See more.](02-replay-letter.pdf) | Dark pickleball motion artwork |
| [One phone. A new perspective.](03-one-phone-letter.pdf) | Minimal phone and court illustration |
| [Black-and-white version](03-one-phone-monochrome-letter.pdf) | Monochrome version of the minimal poster |

Print single-sided in portrait orientation at **Actual size / 100%**. The files
include printer margins and embedded fonts; borderless printing is unnecessary.
Choose the monochrome version for inexpensive photocopying.

The signup code is integrated into a white footer beside the invitation. QR
codes were decoded from 150 dpi renders and checked against the exact signup
URL. PDF links are also clickable.
