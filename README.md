# Vantage

Racket-sport measurements (players, ball, paddles, court position, speed) from a single
phone camera. Capstone project by team Nebula, University of Waterloo.

## Demo

https://github.com/user-attachments/assets/172193ca-42d6-488d-ad7e-fb9f65463d10

Player and ball tracking with the stats overlay (about 20 seconds), from the
[desktop pipeline](pipeline/README.md).

## Current status

- **Desktop pipeline:** player and ball tracking, court calibration, estimated shot/rally
  stats, bounce calls, and a landing heatmap from one fixed-camera video.
- **iPhone app:** runs the detector and ball tracker on-device on imported videos, with
  playback overlays. The Swift tracker matches the Python one frame for frame.
- **Detector:** the fine-tuned `pickleball-v1` model tracks the ball in 61.6% of
  visible-ball frames at 96.2% precision on a held-out clip (confidence threshold tuned on
  that clip), up from 39.6% with the generic model ([details](ml/README.md)).

Generated or local-only (git-ignored): `artifacts/` (Core ML exports), `reports/`,
`input/`, `output/`, `.venv/`.

How the parts connect: models trained in `ml/` are exported by `tools/coreml/` into
`artifacts/`, which the iOS app bundles. The Swift ball tracker in `VantageKit` is a port
of the Python tracker in `pipeline/vantage/`, and its tests replay fixtures generated by
the Python tracker, so a tracker change updates both sides in the same PR.

## Setup

**Python.** `pipeline/`, `ml/`, and `tools/coreml/` share one environment.

1. Install [uv](https://docs.astral.sh/uv/): `brew install uv`
2. From the repository root: `uv sync`

This creates `.venv/` with Python 3.13 and the exact versions in `uv.lock`. Run commands
with `uv run`, for example `uv run vantage --input assets/sideview.MOV`. To add a
dependency, use `uv add <package>` (or `uv add --group ml <package>`) and commit the
updated `uv.lock`.

**Videos.** Videos never go in git; they live in the
[team Drive](https://drive.google.com/drive/folders/1SdQtkB20qAhdSWJeDpUTPMgY6hVcE1Hu) (Capstone - Nebula > Videos). To run the examples,
download `sideview.MOV` into `assets/`. Put your own recordings in `input/`, which is
git-ignored. Small text files that describe videos, such as rally labels in
`ml/labels/rallies/`, stay in git.

**iOS.** Xcode 27.1 on a Mac (pinned in `.xcode-version`; the scripts warn if yours differs).
Follow [ios/README.md](ios/README.md): copy
`ios/Config/Local.xcconfig.example` to `ios/Config/Local.xcconfig` and set your team ID,
export the model, then run `ios/scripts/run_on_iphone.sh`.

## Tests

```sh
scripts/test.sh
```

Runs the pipeline, `ml/`, and `tools/coreml/` Python suites, plus VantageKit's Swift tests
on macOS with Xcode. CI ([.github/workflows/ci.yml](.github/workflows/ci.yml)) runs the same on
every pull request and also builds the iOS app.
